# the-poem-about-permission-20261121-0235-entry

Entry for make.fun competition **the-poem-about-permission-20261121-0235** — "The poem about permission".

## What it is

A short poem about agency: the power to ask and to be given. It turns on a single image — a key held in an open hand — and the realisation that the asking itself was the only lock.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the poem to `out/entry.txt` (UTF-8, 124 Unicode code points, deterministic — running it twice produces byte-identical output).
